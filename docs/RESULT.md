# 移动云盘挂载验证结果

## 结论

Windows WinFsp 和 WSL Ubuntu 24.04 的 Linux FUSE 挂载均通过本地模拟服务下的 T1–T12。Windows 连接中国移动云盘生产 SaaS，实测通过 T1–T10 和 T12，并通过客户端缓存过期触发重新取址的验证。3 项无挂载 HTTP 测试通过。手动 T13 仍待完成，WSL 直连生产 SaaS 超时。

## 生产 SaaS 验证

- 使用已建好的专用目录作为 Windows 挂载根。目录列表返回业务码 `0000`。挂载用例覆盖多级目录、小文件读写、23 MiB 分片文件写入、重挂后随机读、追加、空文件、改名、移动、替换、删除、250 项分页和 Windows 大小写路径。
- 独立调用 Demo 客户端上传随机生成的 23 MiB 文件。取址和 `complete` 均返回 `0000`。EOS 分别接收 10、10、3 MiB，三次 PUT 均返回 HTTP 200。
- 重挂后从 9 MiB 偏移读取 1 MiB，读回内容与原文件一致。独立发送 `Range: bytes=9437184-10485759`，EOS 返回 HTTP 206、`Content-Range: bytes 9437184-10485759/24117248`，响应体为 1 MiB。
- 下载链接返回约 900 秒有效期。将客户端缓存中的有效期设为过去后，下一次未缓存块读取重新调用取址接口，EOS 返回 206，字节校验通过。真实链接自然到期已由模拟服务的短有效期用例覆盖，生产环境此次使用本地缓存过期触发。
- 修复生产目录 `size: null` 导致 WinFsp 属性读取报错的问题，并支持秒传成功响应没有分片地址的情况。验证生成的 4 个子目录已移入回收站，挂载根的原有 3 项保持原样。

## 接口差异与产品化缺口

- 2.8.10 的 /file/update 字段说明写明改名最长 200 个 UTF-8 字节，表格长度列写 255。Demo 对已上传文件采用较严的 200 字节限制，创建仍使用 255 字节。
- /task/get 原文的成功枚举为 Succeed。客户端异步轮询后逐项检查 errCode。模拟端返回 Succeed。
- 分片上限 10000，单次地址上限 100。Demo 实测三片上传。生产 Web HAR 记录了 204 片上传，Demo 的超过 100 片续取仍待实测。
- 修改已有文件会暂存全量数据，关闭时同步上传。产品化需要后台上传、可恢复的失败队列、本地空间管控及更明确的多端冲突处理。
- 覆盖改名先回收目标再移动源，跨目录改名分为移动和改名两个调用。部分成功时可能需要人工恢复。
- Linux 运行、真实鉴权及用户域路由、云端容量与限流、内容审核替代下载响应、常用应用兼容性及部署许可仍待核实。
